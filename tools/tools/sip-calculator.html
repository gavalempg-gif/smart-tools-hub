SIP Calculator – Free Online Tool

SIP (Systematic Investment Plan) એ મ્યુચ્યુઅલ ફંડમાં દર મહિને નિયમિત રોકાણ કરવાની રીત છે.

આ કેલ્ક્યુલેટર વડે તમે જાણી શકો છો કે તમારા માસિક રોકાણથી ભવિષ્યમાં કેટલી રકમ થશે.

કેવી રીતે વાપરવું:

  1. માસિક રોકાણ (Monthly Investment) નાખો
  2. અપેક્ષિત વળતર (Expected Return %) નાખો
  3. સમયગાળો (Years) નાખો
  4. Calculate SIP બટન દબાવો

તમને કુલ રોકાણ, અંદાજિત વળતર અને કુલ મૂલ્ય તરત જ મળી જશે.

આ ટૂલ સંપૂર્ણ મફત છે અને કોઈ રજિસ્ટ્રેશનની જરૂર નથી.
